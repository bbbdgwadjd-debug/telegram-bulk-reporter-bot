# 📱 Telegram Bulk Reporter Bot

بوت متقدم لإرسال إبلاغات جماعية على Telegram مع إدارة كاملة للحسابات والإحصائيات.

## ✨ الميزات

- ✅ **إضافة حسابات متعددة** - أضف حسابات Telegram للإبلاغ منها
- ✅ **كليشات مخصصة** - أنشئ نصوص جاهزة للإبلاغات
- ✅ **إبلاغات جماعية** - أرسل إبلاغات من عدة حسابات في نفس الوقت
- ✅ **تحكم في السرعة** - حدد التأخير بين الإبلاغات
- ✅ **إحصائيات تفصيلية** - اعرض نتائج الإبلاغات (نجح/فشل)
- ✅ **التحقق من الحسابات** - تأكد من وجود الحساب المراد الإبلاغ عليه
- ✅ **قاعدة بيانات محلية** - حفظ آمن للبيانات

## 🚀 البدء السريع

### المتطلبات
- Python 3.8+
- pip

### التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/yourusername/telegram-bulk-reporter-bot.git
cd telegram-bulk-reporter-bot

# تثبيت المكتبات
pip install -r requirements.txt

# نسخ ملف الإعدادات
cp .env.example .env
```

### الإعدادات

1. افتح `.env` وأضف:
   - `BOT_TOKEN` - الحصول عليه من [@BotFather](https://t.me/BotFather)
   - `ADMIN_ID` - معرف Telegram الخاص بك

```env
BOT_TOKEN=your_bot_token_here
ADMIN_ID=your_telegram_id_here
DB_NAME=reporter_bot.db
```

### تشغيل البوت

```bash
python main.py
```

## 📖 طريقة الاستخدام

### الخطوة 1️⃣: إضافة حساب
- اضغط على زر "إضافة حساب"
- أرسل رقم هاتف الحساب الذي تريد الإبلاغ منه

### الخطوة 2️⃣: إضافة كليشة (Template)
- اضغط على زر "إضافة كليشة"
- أرسل اسم الكليشة
- أرسل نص الكليشة (سيُرفق مع كل إبلاغ)

### الخطوة 3️⃣: إرسال إبلاغات
- اضغط على زر "بدء إبلاغات"
- أدخل اسم المستخدم المراد الإبلاغ عليه
- أدخل عدد الإبلاغات
- أدخل التأخير بين الإبلاغات (بالثواني)

### الخطوة 4️⃣: مراجعة النتائج
- اعرض الإحصائيات
- تحقق من الإبلاغات الناجحة والفاشلة
- تأكد من حالة كل حساب

## ⚙️ الإعدادات المتقدمة

- الحد الأدنى: 0.5 ثانية (لتجنب الحظر)

### عدد الإبلاغات
- الحد الأدنى: 1
- الحد الأقصى: 100 إبلاغ
